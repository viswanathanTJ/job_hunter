# Hard Match Rules (user-editable)

These rules are injected into every job analysis. Edit freely — the analyzer reads this
file fresh on each run. Ported from the n8n suitability agent.

- Targeting Backend Engineer / Senior Backend Engineer roles, Mid-Senior level, 3+ years experience.
- Based in Chennai, India. Open to: on-site or hybrid roles ONLY in Bangalore (Bengaluru)
  or Chennai; OR fully remote roles from anywhere (location irrelevant if genuinely remote).
- NOT open to on-site/hybrid roles in any other city, nor any role requiring relocation
  outside India. If a posting requires on-site or hybrid work in a city other than
  Bangalore/Bengaluru or Chennai, or requires relocation, the verdict must be NO
  regardless of role match.
- Compensation target: INR 18-28 LPA, minimum INR 16 LPA. If the posting states
  compensation clearly below the minimum, cap the score at 2.5 and say so in cons.
- Primary stacks are Python (FastAPI/Django) and Java (Spring) — weighted equally.
  The candidate does NOT know Node.js well: if a role's primary/required stack is
  Node.js (or the JD centers on Node/Express/NestJS), cap the score at 3.0 and state
  the Node.js mismatch in cons. Node.js as a nice-to-have alongside Python/Java is fine.
- Be strict: a score of 4.0+ means "worth applying"; scores below 4.0 mean the
  candidate should generally NOT apply.
